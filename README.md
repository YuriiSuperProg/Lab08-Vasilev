## Что изучено

- Чем `void`-метод отличается от метода с `return`: `void` просто выполняет действия и ничего не возвращает, а метод с типом результата обязан вернуть значение на **любом** пути выполнения — иначе компилятор выдаст ошибку `CS0161`.
- Как передавать данные в метод через параметры и как вызывать метод с конкретными аргументами: параметры — это «входные данные» метода, при вызове на их место подставляются аргументы.
- Зачем выносить повторяющийся код в метод: если один и тот же код скопирован в нескольких местах, при исправлении придётся править все копии; метод исправляется в одном месте, а вызывается сколько угодно раз.
